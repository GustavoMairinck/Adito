Muninn

Painel de pesquisa e extensão do Ifes Campus Serra. Ambiente de teste.

⚠️ Base fictícia

A base publicada aqui é gerada automaticamente com nomes e títulos inventados. Serve só para testar a instalação e a atualização.

Windows

Baixe o instalador .exe (ou o .msi) do último Release e execute.

Linux (Debian / Ubuntu)

Cadastre o repositório uma vez:

curl -fsSL {{URL}}/apt/muninn.asc | sudo tee /usr/share/keyrings/muninn.asc >/dev/null
echo "deb [signed-by=/usr/share/keyrings/muninn.asc] {{URL}}/apt ./" | sudo tee /etc/apt/sources.list.d/muninn.list
sudo apt update && sudo apt install muninn

Depois, as versões novas chegam com sudo apt upgrade.

Sem repositório: baixe o .deb do Release e rode sudo apt install ./Muninn_*.deb.

Dados

O instalador não traz a base. No app, abra Administração → Contextos de dados → Atualizar base: ele baixa a versão publicada em dados/manifest.json, confere o sha256 e troca o arquivo, guardando a base anterior.
